# Feature inventory (current rebuild)

## Interactive casting (core product)
1. Live session status (local network IP, AirPlay external display, Wi‑Fi viewer, now casting)
2. Photo slideshow with multi-select, interval control, prev/next, AirPlay route picker
3. Single photo cast preview
4. Video cast with shared AVPlayer, play/pause/seek (±10s), AirPlay external playback
5. Direct media URL cast (mp4 / m3u8 / mov / images) via AVPlayer — not a website wrapper
6. Media remote controlling the in-app cast queue / playback (honest: not IR TV remote)
7. Optional Wi‑Fi screen viewer (ReplayKit JPEG LAN server) with URL copy + QR
8. Recent casts history (on-device)
9. Quick-cast actions on Home

## Supporting
10. Connect / troubleshooting + system AirPlay route picker
11. YouTube / Vimeo link tools → in-app browser (secondary)
12. Built-in browser (secondary)
13. Control Center Screen Mirroring instructions (honest limits)
14. Settings, Privacy/Support URLs, themes, locales

## Intentionally not claimed
- Opening system Screen Mirroring sheet programmatically
- Infrared / manufacturer TV remotes
- Official affiliation with Apple, YouTube, Vimeo, or TV brands
